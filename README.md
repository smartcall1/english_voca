# 작은 탐험가의 영어섬 (English Island)

초등 학습자를 위한 오프라인 완결형 50일 영어 어휘 및 독해 학습 웹 애플리케이션입니다.  
별도의 백엔드 인프라, 데이터베이스, 외부 API 의존성 없이 단일 클라이언트(`Chrome`, `Edge`) 환경에서 동작하며, 음성 합성(Web Speech API), 고해상도 그래픽, 인터랙티브 퀴즈 및 미니게임을 포함한 전체 기능이 네트워크 연결 없이 완전하게 구동됩니다.

---

## 주요 기능 및 사양

### 1. 5개 테마 탐험 지도 (50일 커리큘럼)
- **지역별 단계적 학습 경로**:
  - 1지역 (Day 1–10): 학교 및 교우 관계 중심 어휘
  - 2지역 (Day 11–20): 가정 및 일상생활 어휘
  - 3지역 (Day 21–30): 마을 환경 및 사회 활동 어휘
  - 4지역 (Day 31–40): 자연 탐구 및 관찰 어휘
  - 5지역 (Day 41–50): 상상과 이야기 중심 심화 어휘
- **경로 기반 인터페이스**: SVG 지형 데이터와 50개 노드를 1:1로 정합하여 학습 진행 상황을 직관적으로 시각화합니다.
- **다중 프로필 지원**: 사용자별(Aiden, Luca) 학습 진도, 수집 별점, 완주 배지가 브라우저 로컬 스토리지 및 IndexedDB에 독립적으로 분리 저장됩니다.

### 2. 일일 4컷 만화 및 1컷 집중 뷰어
- **일자별 맞춤 서사**: 50일 전 일정에 걸쳐 매일 고유한 4컷 만화 일러스트와 대사를 제공합니다.
- **분할 뷰어 인터페이스**: 4컷 전체를 한 번에 노출하지 않고, 1컷 단위 대형 일러스트(360×360px)와 대사 카드를 결합하여 시선 분산을 방지합니다.
- **음성 연동**: 각 컷의 말풍선 선택 시 호주 영어 음성(`en-AU` 우선)으로 원어민 발음을 재생합니다.

### 3. 어휘 카드 및 번역 블라인드
- **체계적 어휘 구성**: 일일 12단어, 총 600개 고유 표제어와 호주 교육과정(ACARA v9) 기준 실용 예문을 탑재했습니다.
- **번역 가림(Blind) 메커니즘**: 예문 청취 후 스스로 의미를 유추할 수 있도록 한국어 해석을 기본 가림 처리하며, 토글 인터랙션 시 누적 레이아웃 이동(CLS)이 발생하지 않도록 고정 높이 컨테이너를 적용했습니다.

### 4. 인터랙티브 평가 및 미니게임
- **단어 퀴즈 (Auto-Advance Timer)**:
  - 4지선다형 어휘 평가. 오답 발생 시 큐(Queue) 재등록을 통한 완전 학습 유도.
  - 정답 선택 시 소리 힌트와 나란히 배치된 다음 버튼에 2초 프로그레스 타이머가 작동하여 자동 전환되며, 수동 클릭으로 즉시 이동도 가능합니다.
- **문장 기차 (Sentence Train)**: 토큰화된 어절을 문법 순서에 맞게 배치하는 구문 조립 학습.
- **보물길 탐험 (Treasure Hunt)**: 징검다리 퀴즈를 통한 어휘 의미 매칭 및 연속 정답 콤보 보상 시스템.
- **듣고 배달하기 (Delivery)**: 음성 청취 후 올바른 목적지를 선택하는 청취 훈련.

### 5. 화면 레이아웃 및 반응형 설계
- **무스크롤(0px diff) 레이아웃**: 데스크톱 기준(1440×900) 전체 9개 학습 화면에서 수직·수평 스크롤이 전혀 발생하지 않도록 뷰포트 맞춤형 배치를 준수합니다.
- **반응형 뷰포트 지원**: 고해상도 데스크톱(1920×1080)부터 노트북, 태블릿(iPad 가로/세로), 모바일 기기(390×844)까지 미디어 쿼리를 통한 유연한 그리드 적응을 지원합니다.

## 실행 및 검증

### 1. 실행 방법
정적 HTML 파일로 구성되어 있으므로, 저장소 클론 후 웹 브라우저(`Chrome`, `Edge`)로 `index.html`을 직접 열어 실행합니다. 로컬 파일 시스템(`file:///`) 프로토콜에서도 완벽하게 구동됩니다.

### 2. 자동화 테스트 실행
Node.js 환경에서 아래 명령어를 통해 단위 테스트, 무결성 검사, 뷰포트 레이아웃 검증을 실행할 수 있습니다.

```bash
# 코어 로직, 데이터 무결성 및 복구 검사
node tests/core.test.cjs
node tests/content.test.cjs
node tests/reset.test.cjs

# 1440×900 뷰포트 기준 스크롤 발생 여부(0px) 검증
node tests/verify-all-screens.js

# 다중 해상도 반응형 레이아웃 및 가로 오버플로우 검증
node tests/test-responsive.cjs

# 데이터 영구 지속성 및 퀴즈 자동 전환 검증
node tests/test-stars-persistence.cjs
node tests/test-quiz-autoadvance.cjs

# 전체 통합 브라우저 E2E 검증
node tests/browser.test.cjs
```

## 보안 및 데이터 관리 정책
- **외부 통신 배제**: 사용자 데이터(학습 진도, 별점, 프로필)는 원격 서버로 전송되지 않으며, 사용자의 브라우저 내 로컬 저장소에만 보존됩니다.
- **개인 식별 자산 격리**: 로컬에서 등록된 개인 프로필 이미지(`profile_*.png`) 및 개인 사진 원본(`*.jpg`, `*.jpeg`, `*.heic`)은 `.gitignore` 정책을 통해 원격 Git 저장소에 추적되거나 커밋되지 않도록 보안 처리되어 있습니다.
