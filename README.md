# 작은 탐험가의 영어섬

Aiden과 Luca를 위한 **50일 생활 영어 학습 앱**입니다. `index.html`을 Chrome 또는 Edge에서 열면 실행됩니다. 설치·로그인·서버가 필요 없으며, `assets`와 JavaScript/CSS 파일을 포함한 폴더 전체를 함께 보관하세요.

## 달라진 점

| 이전 | 개편 후 |
| --- | --- |
| 30일 격자 목록 | 5개 탐험 지역, 지형·물길·다리·이어진 길 위의 50개 목적지 |
| 작은 메뉴와 설명 | 기본 본문 22px, 주요 선택지와 학습어 확대, 설정에서 26px 본문 선택 |
| 하루 3단어 | 하루 12항목, 총 600개 고유 항목과 예문·번역 |
| 풍선·짝맞추기 | 보물길 탐험, 문장 기차, 듣고 배달하기 |
| 이모지 만화 | 실제 그림 4컷 만화 10편, 큰 말풍선·대사 음성·한국어 풀이 |

만화는 50편이 아니라 **각 5일 동안 함께 읽는 10개 에피소드**입니다. 매일 해당 단어로 그림을 설명하는 연결 미션을 제공합니다. 그림에 글자를 새기지 않고 HTML로 대사를 표시해 확대·음성 읽기가 가능합니다.

## 학습과 기록

1. 지도에서 원하는 Day를 선택합니다. 필요한 주제로 바로 이동할 수 있습니다.
2. 단어 12개를 확인합니다. 4개씩 세 묶음으로 나누어 학습해도 됩니다.
3. 만화의 네 컷을 읽거나 듣습니다.
4. 뜻에 맞는 단어를 고릅니다. 틀린 문제는 다시 시도할 수 있습니다.
5. 원하는 게임 한 가지를 끝냅니다. 모든 게임에는 시간제한이 없습니다.

미션당 별 1개와 네 미션 완주 보너스 별 3개를 받습니다. 반복 플레이로 별을 중복 지급하지 않습니다. 지역별 10일을 완주하면 탐험 배지를 받습니다.

Aiden과 Luca는 브라우저 안에서 독립적인 진도를 저장합니다. 기존 30일 버전의 테스트 기록은 이전하지 않으며 **새 과정은 두 프로필 모두 진도 0·별 0으로 시작**합니다. 브라우저나 파일 위치를 바꾸면 저장 공간이 달라질 수 있습니다. 저장이 막히면 앱에서 안내하고 현재 창에서는 학습을 계속합니다.

설정의 **Aiden 초기화 / Luca 초기화**에서 아이별 진도·별·배지를 지울 수 있습니다. 확인 단계에서 해당 아이 이름을 다시 표시하며, 다른 아이의 기록은 유지됩니다. 저장에 실패하면 초기화를 진행하지 않습니다.

영어 음성은 기기의 `en-AU` 음성을 우선 사용합니다. 없으면 다른 영어 음성을 사용합니다. 음성 지원·음질·오프라인 발음 가능 여부는 브라우저 및 설치된 음성에 따라 달라집니다. 학습 화면·그림·게임은 외부 CDN 없이 로컬 파일로 동작합니다.

## 교육 자료와 범위

ACARA v9 Foundation–Year 2와 NSW 교육부의 어휘 지도 방향을 참고해 직접 선정했습니다. **정부 지정 필수 600단어 목록이나 공식 인증 교재는 아닙니다.** 597개 단일 단어와 3개 짧은 표현을 포함합니다. 파닉스와 실제 대화 학습을 대신하는 과정도 아닙니다.

선정 근거와 공식 출처는 [curriculum-notes.md](curriculum-notes.md)에 정리했습니다. 그림 제작 프롬프트는 [assets/prompts.md](assets/prompts.md)에 있습니다.

## 파일과 검증

- `curriculum.js`: 50일 어휘·예문·번역
- `comics.js`, `assets/`: 10편의 만화 대사와 그림
- `app.js`, `styles.css`: 학습 화면·게임·음성
- `core.js`: 진도·보상·선택지 판정
- `tests/`: 데이터·로직 검사 및 별도 Chrome 프로필의 자동 화면 검증

코드·데이터 검사는 `rtk proxy node --test tests/core.test.cjs tests/content.test.cjs`로 실행합니다. 브라우저 검증 스크립트는 이 PC에 이미 설치된 Puppeteer/Chrome을 사용하며 `tests/browser-profile`에 테스트 기록을 분리합니다. 앱 사용자에게 Puppeteer 설치는 필요하지 않습니다.

실제 검증 결과는 [검토 기록](tasks/todo.md), [자동 화면 검증 결과](tests/browser-results.json), [화면 캡처](tests/screenshots/)에서 확인할 수 있습니다.
