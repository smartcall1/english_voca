# 작은 탐험가의 영어섬 (Little Explorers' English Island) 🏝️

**Aiden과 Luca를 위한 50일 몰입형 초등 생활 영어 학습 웹 애플리케이션**입니다.  
설치·로그인·백엔드 서버 없이 브라우저(`Chrome`, `Edge`)에서 `index.html`을 열면 즉시 실행되며, 오프라인 환경에서도 모든 기능(오디오, 일러스트, 폰트, 미니게임)이 완벽하게 동작합니다.

---

## ✨ 핵심 기능과 특징

### 1. 5개 테마의 테마별 모험 지도 (50일 여정)
- **5개 고유 탐험 지역**:
  1. **친구의 숲 (Day 1–10)**: 학교와 친구, 잔디 오솔길과 오두막
  2. **포근한 마을 (Day 11–20)**: 집과 일상, 조약돌길과 풍차 마을
  3. **무지개 항구 (Day 21–30)**: 마을과 생활, 모래사장과 데크길, 등대와 돛단배
  4. **초록 탐험섬 (Day 31–40)**: 자연과 탐구, 정글 오솔길과 모험 캠프
  5. **상상의 산 (Day 41–50)**: 생각과 이야기, 신비로운 보랏빛 은하수길과 별빛
- **완벽한 길 정합성**: SVG 기반 지형과 실제 Day 1~50 목적지 노드가 유기적으로 연결되어 시각적 성취감을 줍니다.
- **실제 주인공 얼굴 아바타 말(Token Pin)**: Aiden과 Luca의 실제 사진을 정밀 추출·가공한 원형 황금 아바타 말이 현재 학습 날짜 노드 위에 세워져 통통 뛰며, 아이들이 진짜 모험의 주인공이 된 몰입감을 선사합니다.

### 2. 50일 전편 고유 고화질 4컷 만화 & 1컷 집중 뷰어
- **50편 전편 고유 일러스트 (`assets/comic-01.png` ~ `comic-50.png`)**:
  - 재탕 없는 50일 맞춤형 4컷 만화 탑재.
  - 당일 배운 핵심 단어가 만화 대사와 스토리에 자연스럽게 녹아들어 복습 효과 극대화.
  - 두 소년 탐험가 **Aiden**과 **Luca**가 주인공으로 등장하는 따뜻한 그림체.
- **1컷 집중 대형 뷰어**:
  - 4컷을 한 번에 보여주지 않고 **1컷씩 대형 삽화(360×360px) + 대형 말풍선 대사 카드**로 집중도 향상.
  - 상단 컷 내비게이션(`1컷`~`4컷`), '← 이전 컷', '다음 컷 →' 및 '✓ 이 컷을 읽었어요' 버튼 제공.
  - '이 컷을 읽었어요' 터치 시 맑은 효과음과 함께 다음 컷으로 자동 전환.

### 3. 단어 카드 & 예문 우리말 뜻 블라인드
- **하루 12단어 체계적 학습**:
  - 총 600개 고유 표제어와 호주 초등 교육과정(ACARA v9) 기반 실용 예문.
  - 원어민 발음 듣기(`en-AU` 우선 매핑) 및 따라 하기.
- **예문 우리말 뜻 블라인드(가림) 시스템**:
  - 영어 문장을 먼저 듣고 뜻을 스스로 유추할 수 있도록 우리말 해석 기본 가림 (`💡 뜻 가림 · 터치해서 우리말 뜻 보기`).
  - 터치 시 부드럽게 풀리며 뜻을 확인하고, 필요 시 `🙈 다시 가리기`로 셀프 퀴즈 가능.
  - 상태 전환 시에도 카드 높이가 일정하게 유지되는 CLS(누적 레이아웃 이동) 0 설계.

### 4. 3가지 재미있는 미니 게임
- 🏴‍☠️ **보물길 탐험 (Treasure Hunt)**: 6개의 징검다리 뜻 퀴즈를 맞히며 섬 끝의 보물상자를 여는 게임.
- 🚂 **문장 기차 (Sentence Train)**: 흩어진 영어 단어 블록을 순서대로 조립하여 칙칙폭폭 문장 기차를 출발시키는 게임.
- 🚚 **듣고 배달하기 (Van Delivery)**: 영어 소리를 듣고 올바른 우편함으로 소포를 배달하는 리스닝 게임.

### 5. 아동 친화 터치 인터페이스 & 1440×900 무스크롤
- **태블릿/터치 모니터 최적화**: 큼직한 터치 버튼, 직관적인 시각 피드백, 부드러운 반응형 인터랙션.
- **스크롤 제로(0px) 보장**: 1440×900 전체화면 기준 9개 전 화면(지도, 단어, 만화, 퀴즈, 게임 3종, 보상)에서 스크롤바가 생기지 않는 완벽한 뷰포트 맞춤 레이아웃.

### 6. 독립 프로필 & 별/배지 보상 체계
- **Aiden과 Luca의 독립된 진도 관리**: 상단 헤더의 실제 얼굴 썸네일 버튼을 통해 두 아이의 프로필을 직관적으로 전환하며, 학습 진도, 별 개수, 배지가 로컬 스토리지에 분리 저장됩니다.
- **화려한 보상 연출**: 미션 완주 시 별이 날아와 박히는 물리 파티클 및 팡파레 효과음.
- **지역별 탐험 배지**: 10일 단위 지역을 완주할 때마다 특별한 탐험 배지 수여.

## 🚀 실행 방법

### 일반 사용자
1. 본 저장소를 다운로드하거나 클론합니다.
2. `index.html` 파일을 더블 클릭하여 크롬(Chrome) 또는 엣지(Edge) 브라우저에서 실행합니다.
3. 별도의 웹 서버나 인터넷 연결 없이 즉시 모든 기능을 이용할 수 있습니다.

### 개발 및 자동화 테스트
Node.js 환경에서 아래 명령어로 단위 테스트 및 브라우저 E2E 검증을 실행할 수 있습니다:

```bash
# 코어 로직 및 50일 어휘/만화 데이터 무결성 검사
node --test tests/core.test.cjs tests/content.test.cjs tests/reset.test.cjs

# 1440x900 전체 화면 스크롤 제로(0px diff) 검증
node tests/verify-all-screens.js

# 예문 블라인드 기능 검증
node tests/test-blind.cjs

# 브라우저 E2E 통합 시나리오 26개 검증
node tests/browser.test.cjs
```
