# 사용자 피드백 반영 기준

- 탐험 지도는 격자가 아닌 지형·길·목적지·현재 위치를 보여야 한다.
- 메뉴·설명·선택지·말풍선까지 확대하고 노트북 화면에서 확인한다.
- 하루 분량과 기간은 데이터로 센다. 공식 교육 방향과 자체 선정 목록을 구분한다.
- 게임은 다른 조작과 목표, 오답 후 회복을 제공한다.
- 만화는 이모지로 대체하지 않는다. 인물·장소·사건·해결을 실제 그림으로 보여준다.
- 문법 검사를 실제 화면 검증으로 대신하지 않는다.
- 기존 학습 기록은 사용자 확인 결과 테스트용이다. 이번 개편에서는 기록 이전·보존 UI를 만들지 않고 새 진도와 별을 0에서 시작한다.
