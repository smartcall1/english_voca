### 검증 중 수정한 문제
1. 축하 알림이 다음 게임 버튼을 가림 → 알림이 포인터 입력을 가로채지 않도록 수정.
2. 게임 완료 후 같은 놀이 마당 탭을 눌러도 결과에 머무름 → 메뉴 선택 화면으로 복귀하도록 수정.
3. 카드·문제 전환 시 키보드 포커스가 사라짐 → 주 학습 영역으로 복원.
4. 모바일 설정 버튼과 지도 제목 줄바꿈 → 좁은 화면의 배치와 버튼 폭 보정.
